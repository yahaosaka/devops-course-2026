# Мой пет-проект

Идея: Telegram-бот для учёта личных расходов — пишешь «кофе 250», бот сохраняет трату и по команде /report присылает сводку за месяц по категориям.
Стек: Python 3.12, aiogram 3, SQLite
Цель: научиться упаковывать бота в Docker и настраивать автоматический деплой через GitHub Actions

## Сроки реализации
- Октябрь: MVP — команды добавления траты и /report
- Ноябрь: Docker-образ и деплой через GitHub Actions
