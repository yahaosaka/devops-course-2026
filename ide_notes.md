# Git в VS Code и в терминале

## Удобно в VS Code
1. Панель Source Control: изменённые файлы видны списком, один клик открывает diff «было/стало» рядом.
2. Индексация отдельных файлов и даже отдельных строк кнопкой «+» без ручного git add.
3. Цветные метки в редакторе прямо у строк, которые были добавлены или изменены после последнего коммита.

## Удобнее в терминале
1. Сложные операции с историей — git rebase -i, git reflog, git cherry-pick: в терминале видно, что именно происходит, и это работает на любом сервере по SSH.
